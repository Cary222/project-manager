## 1. 数据库层（`prisma/schema.prisma`）

### 1.1 新增 `WeeklyReport` 模型

```prisma
model WeeklyReport {
  id                String                 @id @default(cuid())
  userId            String
  weekStart         DateTime               // 周一 00:00
  weekEnd           DateTime               // 周日 23:59
  title             String
  content           String    @db.Text     // Markdown 正文
  attachments       Json?                  // PkmAttachment[] 序列化（同 PkmNote）
  aiSummary         String?   @db.Text     // AI 生成的结构化总结（Markdown）
  aiSummaryAt       DateTime?
  aiSummaryPartial  Boolean   @default(false)
  submittedAt       DateTime  @default(now())
  updatedAt         DateTime  @updatedAt

  user     User                  @relation(fields: [userId], references: [id], onDelete: Cascade)
  projects WeeklyReportProject[]

  @@unique([userId, weekStart])
  @@index([weekStart])
  @@index([userId, submittedAt(sort: Desc)])
  @@schema("pm")
}

model WeeklyReportProject {
  reportId   String
  projectId  String

  report  WeeklyReport @relation(fields: [reportId], references: [id], onDelete: Cascade)
  project Project      @relation(fields: [projectId], references: [id], onDelete: Cascade)

  @@id([reportId, projectId])
  @@schema("pm")
}
```

### 1.2 `User` 模型新增 `bio` 字段

```prisma
model User {
  bio            String?          @db.Text
  weeklyReports  WeeklyReport[]
}
```

### 1.3 `Project` 模型补关联

```prisma
model Project {
  weeklyReports  WeeklyReportProject[]
}
```

**执行**：`pnpm prisma migrate dev --name add_weekly_reports_and_user_bio`

### 2.5 v3 目录结构（修正后）

```
app/
├── api/                              ← 所有 API 都在这（Next.js 约定 + 项目惯例）
│   ├── reports/                      ← 报表业务 API（v3 新增）
│   │   ├── stats/route.ts            ← PR2 报表聚合
│   │   ├── health-summary/route.ts   ← PR2 健康度 AI
│   │   └── weekly-reports/           ← PR1 周报 CRUD（v3 已落盘）
│   │       ├── route.ts              ← GET / POST
│   │       └── [id]/
│   │           ├── route.ts          ← GET / PATCH / DELETE
│   │           └── regenerate/route.ts ← PR4 手动重生成
│   ├── tickets/...                   ← 已有
│   ├── projects/...                  ← 已有
│   ├── ai/...                        ← 已有
│   └── ...
└── reports/                          ← 报表业务页面壳（业务聚类）
    ├── page.tsx                      ← 报表首页
    └── weekly-reports/               ← 周报页面壳
        ├── page.tsx                  ← 周报列表
        ├── new/page.tsx              ← 新建周报
        └── [id]/page.tsx             ← 周报详情
```

**核心原则**：
- **所有 `route.ts` 一律在 `app/api/` 下**
- **业务聚类只对页面壳生效**
- **`weekly-reports` 是 `reports` 的子目录**（页面壳），`weekly-reports` 在 `app/api/reports/` 下平铺（API）

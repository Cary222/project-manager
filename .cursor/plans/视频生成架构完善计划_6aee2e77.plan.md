# 视频生成架构完善计划

## 核心架构原则（最终决策）

> **Provider 只负责生成并返回 `providerVideoUrl`；FileAsset Storage Layer 负责决定 URL / 数据库 / 对象存储如何持久化；业务 Handler 不直接关心具体存储实现。**

```
Agnes
 ↓
VideoProviderResult { providerVideoUrl }
 ↓
video.handler
 ↓
saveVideoAsset(url, mimeType, size)    ← Storage Layer 接口
 ↓  当前实现                              ↓  未来只换这一层
REMOTE_URL FileAsset                   OBJECT_STORAGE FileAsset

/file-assets/:id
 ↓ 302
Browser
```

当未来接入对象存储时，只改 `saveVideoAsset()` 内部——**Video Provider、Worker、Message、UI 都不用改**。

---

## 问题根因

```
Worker (独立进程)
  │
  │ generateSingleVideo()
  │ ↓
  │ video-generator.ts Agnes provider
  │ ├─ POST /videos → video_id
  │ ├─ 轮询 GET /agnesapi?video_id=xxx
  │ └─ fetch(videoUrl) → 下载 bytes ← 失败点：10-50MB
  │
  │ AiFileAsset.create(bytes: videoBytes) ← PostgreSQL 写入失败
  │
  │ emitMessageDelta() ← 无效：globalThis 跨进程
```

## 修复后架构

```
Frontend                Worker
    │                    │
    │ POST /generate     │
    │ ← messageId        │
    │                    │
    │ GET /messages/id   │ generateVideo()
    │ (polling 2s)      │ ↓
    │ ← progress/status  │ Agnes Provider
    │                    │ ↓
    │                    │ videoUrl (只返回URL，不下载)
    │                    │ ↓
    │                    │ AiFileAsset
    │                    │ ├─ storageType: "REMOTE_URL"
    │                    │ ├─ storageKey: videoUrl
    │                    │ └─ bytes: null
    │                    │
    │ GET /file-assets/:id
    │ ← 302 → videoUrl (安全校验后)

Browser
    │
    │ <video src="/api/ai/file-assets/:id">
    │ ← 302 → Agnes Video URL
    │ ← 200 video/mp4
```

### 1.2 修改 video-generator.ts Agnes provider

**文件**: `features/ai/llm/video-generator.ts`

核心改动：Agnes provider **只返回 URL，不下载 bytes**。

```typescript
// 修改前（第 244-261 行）：下载视频到 bytes
const videoRes = await fetch(videoUrl);
const arrayBuffer = await videoRes.arrayBuffer();
return {
  videos: [{ bytes: Buffer.from(arrayBuffer), mimeType, size: arrayBuffer.byteLength }],
  model: modelName,
  provider: "agnes"
};

// 修改后：返回 URL + 元数据
return {
  videos: [{
    url: videoUrl,           // Provider URL
    mimeType: mimeType,
    size: videoResult.size ?? undefined,  // null 表示未知，不要写 0
  }],
  model: modelName,
  provider: "agnes"
};
```

同时需要更新 `GeneratedVideo` 类型：

```typescript
export interface GeneratedVideo {
  url: string;           // Provider URL（REMOTE_URL 模式）
  mimeType: string;
  size?: number;         // undefined 表示未知
  bytes?: never;         // 明确：REMOTE_URL 模式不使用 bytes
}
```

### 1.3 修改 video.handler.ts

**文件**: `worker/background/handlers/video.handler.ts`


## Phase 2: API 安全 + Provider 抽象

### 2.1 file-assets API 增加安全校验

**文件**: `app/api/ai/file-assets/[id]/route.ts`

```typescript
// REMOTE_URL: 重定向到 Provider URL
if (asset.storageType === "REMOTE_URL" && asset.storageKey) {
  try {
    const url = new URL(asset.storageKey);
    
    // 安全校验：只允许 https
    if (url.protocol !== "https:") {
      return NextResponse.json(
        { error: "Invalid storage URL protocol" },
        { status: 400 }
      );
    }
    
    // 限制允许的 Provider 域名（可选，可扩展）
    const allowedDomains = [
      "apihub.agnes-ai.com",
      "agnes-ai.com",
    ];
    const isAllowed = allowedDomains.some(domain => 
      url.hostname === domain || url.hostname.endsWith(`.${domain}`)
    );
    
    if (!isAllowed) {
      return NextResponse.json(
        { error: "Provider URL not allowed" },
        { status: 400 }
      );
    }
    
    return NextResponse.redirect(asset.storageKey, 302);
  } catch {
    return NextResponse.json(
      { error: "Invalid storage URL" },
      { status: 400 }
    );
  }
}
```

```typescript
/**
 * Video Provider 统一接口

export interface VideoProviderConfig {
  apiKey: string;

export interface VideoGenerationInput {

export interface VideoProviderResult {
  /** Provider 返回的视频 URL */
  providerVideoUrl: string;
  /** 视频时长（秒） */
  duration?: number;
  /** MIME 类型 */
  mimeType: string;

export interface VideoProvider {

   * 生成视频
```

### 2.3 创建 video-providers/agnes.ts

**文件**: `features/ai/llm/video-providers/agnes.ts`

从 `video-generator.ts` 迁移 Agnes 实现，核心逻辑不变，只是：
1. 返回 `{ providerVideoUrl, duration, mimeType, size }` 而不是下载 bytes
2. 不调用 `fetch(videoUrl)` 下载视频

```typescript
import type { VideoProvider, VideoProviderConfig, VideoGenerationInput, VideoProviderResult } from "./types";

export class AgnesVideoProvider implements VideoProvider {
  readonly name = "agnes";
  readonly displayName = "Agnes Video";

  async generate(input, config, onProgress) {
    // 1. 创建视频任务 POST /videos
    // 2. 轮询 GET /agnesapi?video_id=xxx 直到完成
    // 3. 返回 URL（不下载）
    // 4. onProgress 回调用于更新 DB
    
    return {
      providerVideoUrl: metadata.url,
      mimeType: "video/mp4",
      size: undefined,  // Agnes 未返回 size
    };
  }
}
```

### 2.4 重构 video-generator.ts 调用 Registry

**文件**: `features/ai/llm/video-generator.ts`

```typescript
import { getVideoProvider, detectProvider } from "./video-providers/registry";

export async function generateVideos(params, onProgress) {
  const provider = detectProvider(params.modelRef, params.baseURL);
  const providerImpl = getVideoProvider(provider);
  if (!providerImpl) {
    throw new Error(`Unknown video provider: ${provider}`);
  }
  
  const result = await providerImpl.generate(
    { prompt, model: modelName, imageUrl: params.imageUrl },
    { apiKey, baseURL },
    onProgress
  );
  
  return {
    videos: [{
      url: result.providerVideoUrl,
      mimeType: result.mimeType,
      size: result.size,
    }],
    model: result.providerVideoUrl.includes("agnes") ? "agnes" : provider,
    provider: provider,
  };
}
```
